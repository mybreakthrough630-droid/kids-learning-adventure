每日10分鐘教學流程

短時間、高頻率、每日重溫，比一次過做很久更有效。

重溫 · 2分鐘

快速重讀昨日2至4張音卡。小朋友先講音，不講字母名稱。

3

新音 · 3分鐘

每日只教一個新音：聽例字、看口形、在空中寫字母，再說一個同音開首的字。

3

拼讀拆音 · 3分鐘

用新音拼兩個字，再把其中一個字拆成獨立音素。每個音都要由左至右指讀。

2

Tricky word與句子 · 2分鐘

讀一個tricky word，再讀一句含有今日新音的短句，結束時稱讚具體進步。

五階段學習路線

  • Phase 1：先玩押韻、節奏、環境聲音和口頭分音遊戲。
  • Phase 2：由 s, a, t, p, i, n 開始，盡快拼出 sat、pin、tap 等字。
  • Phase 3：學常見雙字母音和三字母音，例如 sh、ch、ai、igh。
  • Phase 4：不急着加新音，集中練相連輔音，例如 stop、frog、tent。
  • Phase 5：比較同音不同寫法、分離二合字母和同一字母的不同讀音。
